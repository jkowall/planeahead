# Seed data licences

Every file in this directory is derived from a public upstream source by
`scripts/fetch-seed-data.mjs`, except the two curated timezone files. `MANIFEST.json` records,
per upstream file, the URL, SHA-256, byte count, the `Content-Length` the server sent, the
fetch time and the licence; per derived file, the row count and bytes.

| Derived file                                      | Upstream                                                        | Licence                   | Notes                                                                                                                                                                                                                                       |
| ------------------------------------------------- | --------------------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `airports.filtered.csv`                           | OurAirports `airports.csv` (David Megginson)                    | Unlicense / public domain | Filtered to `scheduled_service = yes` or `type` in (`large_airport`, `medium_airport`); parsed by header name.                                                                                                                              |
| `airports.filtered.csv` (`tz_mwgg` column)        | mwgg/Airports `airports.json`                                   | MIT                       | Timezone joined by ICAO, ident, GPS code, then IATA.                                                                                                                                                                                        |
| `airports.tz-review.json`                         | geo-tz (code MIT, boundary data ODbL) applied at fetch time     | see note                  | Review input only. Never read by the loader, never shipped. Candidates for airports mwgg does not cover.                                                                                                                                    |
| `airports.tz-overrides.json`                      | curated                                                         | project data              | Hand-curated on 2026-09-20 by `scripts/curate-tz-overrides.mjs`: each candidate accepted only when IANA `zone1970.tab` lists the airport country for the zone. Committed as reviewed data; no ODbL derivation happens at build or run time. |
| `airports.tz-rejected.json`                       | curated                                                         | project data              | Candidates that failed the country check. The loader skips these with a warning.                                                                                                                                                            |
| `airlines.csv`                                    | vradarserver/standing-data `airlines/schema-01/airlines.csv`    | CC0 1.0                   | Verbatim (BOM stripped).                                                                                                                                                                                                                    |
| `optd_airlines.subset.csv`                        | OpenTravelData `optd_airlines.csv`                              | CC BY 4.0                 | Rows with `env_id` empty and a 3-letter code; nine columns kept. Attribution: OpenTravelData (https://github.com/opentraveldata/opentraveldata).                                                                                            |
| `aircraft-types.csv`                              | vradarserver/standing-data `model-type/schema-01/*.csv`         | CC0 1.0                   | Deduped on ICAO preferring `IsActive = 1`; `-` designators dropped.                                                                                                                                                                         |
| `aircraft-types.csv` (`wake_turbulence = J` rows) | ColtJD45/icao-aircraft-designator-list `icao_aircraft_data.csv` | MIT                       | Only the wake turbulence category J (Super) is taken; a frozen 2025-08-19 snapshot.                                                                                                                                                         |

Attribution for CC BY 4.0 data (OpenTravelData) is carried in this file and in
`docs/schema-review.md`. The IANA `zone1970.tab` and `backward` files used by the curation script
are public domain and are fetched at run time, not committed.
